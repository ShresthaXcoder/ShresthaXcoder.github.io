Navigation

Overview
Tokens
API
The kit ships as plain HTML + CSS — drop it in, no build step required.
Every colour, radius and font is a CSS variable on :root.
Components are class-based; copy the markup and you're done.

Accordion

Is it really dependency-free? +
Yes — no frameworks, no runtime, just CSS and a sprinkle of vanilla JS for interactions.
Can I re-theme it? +
Override the tokens on :root and every component follows instantly.
Does it work offline? +
Fully — the effects are CSS-only, so it renders with no network at all.
